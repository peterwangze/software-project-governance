# 0.101.1 发布范围

REL-106 从上版标签 `v0.101.0`（提交 `9ab770a762c7`）累计组装。本版优先解决经 GitHub 市场安装后第一次调用 `/governance` 时 Python 找不到脚本的问题。FIX-547 已进入组装基线 `9682056f`。

| 范围 | 可核对的结果 |
| --- | --- |
| 市场入口与独立技能（FIX-547） | 从当前宿主提供的主技能文件或插件包定位脚本，在另一个目录打开用户项目并首次启动。输出分别标明安装技能目录和用户项目根。搬移或缺少安装时，旧目录不能借用相邻副本。 |
| 验证器拆分（FIX-525 至 FIX-541） | CLI 启动和分发保持公开入口。各检查由对应模块加载，独立安装下可复验版本新鲜度、架构规则及审查路径。以候选的测试、兼容性和架构检查核实。 |
| 风险、审查与宿主（FIX-483、FIX-514 至 FIX-524） | 风险汇总复用统一口径，读取审查提交时批量查询 Git；冲突的审查证据在登记前被拒绝。显式宿主配置、写入者恢复、DSH 隔离与启动后提问沿各自回归验证。 |
| 发布账本、包内容与健康检查（FIX-542 至 FIX-546） | 检查报告区分项目与插件的发布账本；包包含能力检查所需契约；历史回执查询批量读取 Git 对象，延后表述按其上下文判断。 |

以 `git log --no-merges v0.101.0..9682056f` 复查含本次修复的累计源码。发布者按[核对清单](release-checklist-0.101.1.md) 在独立消费项目验收候选和公开分发物。
