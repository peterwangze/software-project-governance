## 1. 版本定位

0.87.0 收口后热表全清（25/25），候选池为唯一工作面。0.88.0 承载 DEC-226 出槽清单 + 本会话审查留票族的**全部已登记项**（用户 DEC-229 一次性闭环授权）：执法升级（write-guard WARN→BLOCK 分族）、存储架构首表（decision-log JSON 权威化）、能力铺开（closure 取消/重开/接管 + 回合心跳 + 并行段识别）、卫生批（审计章/账本/bisect/环清理/观察项）。

**不承载**：主文件大拆解（arch 明确告诫——迁移期不做顺便重构）、e2e legacy 快照单源化（定案为 backport 政策制度化，见 §2/§8-Q4）。

**核心风险对冲（arch 总体提醒——本版最高优先不变量）**：guard 依赖基线/台账 → 台账依赖写入器 → 写入器正迁移存储 → 发布依赖检查结果——**系统正在用被修改的机制证明自己正确，闭环内部共同出错的表现是高可信度假绿**。对冲交付物：独立迁移/恢复证明包（固定源 commit + 数据摘要、冻结窗完整性双向摘要复核〔冻结起点↔切换提交——REVIEW-R0 P2-3〕、记录级前后比对、故障注入、回退演练含迁移后新增行、绑定发布提交的验证报告；**独立性操作化三条〔REVIEW-R0 P2-4〕：①比对裁决一律用切换前旧 md 解析器——不消费新读适配器（防循环论证）；②校验器用切换前版本；③独立性声明作为证明包报告必填节**）——由 FEAT-061 验收面强制承载。
