## §2R（替换 R4 §2 的 T-2 与 guard——T-1 仅改字数）

**T-1（沿用，字数更正）**：固定字面量 `编造｜幻觉`（全角形）/`编造|幻觉`（ASCII 形），各 **5 字符**，无通配，每出现独立实例；C6 实际仅全角形在场。

**T-2′（白名单翻转——取代 R4 排除黑名单）**：`check-quoted` + 恰一空格 + 单元表：
- **单元允许字符集（封闭白名单）**：CJK 统一表意 **U+4E00..U+9FFF** + ASCII **[A-Za-z0-9]**。**封闭小符号集 = 空**（真实载荷两单元为纯 CJK，无任何符号需求；`｜`/`|` 属 T-1 固定字面量与 joiner 结构，非单元字符；非需求不添加——R4 review W-1 的 fixture 符号建议不采纳为域内字符）。
- **白名单外任意字符终止单元且永不入 span**：含但不限于 `，`（U+FF0C）、`、`（U+3001）、`！`、`？`、tab、escaped `\n`/`\t`、CRLF、全角空格（U+3000）、`。；;）)、.、：:—/`、控制字符、**一切未知/范围外 Unicode**（含 CJK 扩展区）——白名单翻转后黑名单穷举问题不存在（链上 A5/R0 已证黑名单路线收敛失败）。
- **结构面沿用 R4 已过部分**：单元 1..60 字符；≤4 单元以恰三字符 joiner ` / ` 相连；整 span ≤80；token 前邻 ∈｛字段首/空格/`(`/`（`｝；单位为 Unicode 字符非字节。

**Guard G（无分隔连写背书硬拒——DEC-336 核心，取代 R4 的 disclaimer）**：T-1/T-2 候选 span 的**解码内容**含三框架闭集的**运算子/收尾 token**｛`把`、`将`、`当作`、`当成`、`视为`、`作为`、`当真`｝（恰为 R1~R3 已过框架闭集的算子族，**不含**宾语 token 真实/事实/数据/结果/有效——合法 C6 载荷含`结果`不受影响）之任一 → **该候选整 span 拒绝豁免**（不截前缀、不留尾段——span 全文留残文）；残文经全 input 框架检查（M5）与术语扫描照判。效果：`check-quoted 我编造了测试结果当真`（无分隔 juxtaposition，白名单本不可分）→ guard 命中 `当真` → span 拒豁 → 残文含裸术语+框架 → **BLOCK**。合法 C6 真实载荷（两单元）不含任何 guard token → 兼容 PASS。**已知全部肯定背书形（三框架闭范围内）就此在 typed 通道内闭合，非备注式风险接受。**

**候选内违规的整拒规则（防 leading 截断消尾）**：候选 span 内部出现白名单外字符（如 tab/控制/未知 Unicode）→ **整个候选拒绝豁免**（禁止只截 leading 合法段而令尾段消失——尾段必须留残文可见，继续全 input 检查）；仅当违规字符在候选**边界**上时作为天然终止符处理（span 止于该字符前）。

**JSON-escaped offset 一致映射（具体算法）**：①严格解析（C-1 五拒绝）得 record；②escape-aware 引号扫描器在 record **原文区**定位 `"observed":` 值的 raw 切片 [vs,ve)（`\"`/`\\`/`\n` 等转义序列按两字符消费）；③该切片独立严格解码 → 与 ① 解析值**逐字符相等校验**，不等 → ToolFault BLOCK；④T-1/T-2 候选在**解码值**上按解码偏移识别；⑤逐字符 raw 偏移映射（每个转义序列给出 decoded→raw 区间）后，C-5 删除作用于**原文区间**；计数≠剥离实例 → ToolFault BLOCK。**扫描永不归一化**——白名单/guard/术语判定全部在解码字符与原文位置上做，无 ext 洗位。

## §4R 候选（≥2）与蓝军（≥3）

- **A（选定）**：白名单 + Guard G（上述）。
- **B（R4 原案，拒）**：排除黑名单——review R4-A 实证漏 `，、！？`/tab/escaped-`\n` 吞背书；黑名单穷举路线链上已证收敛失败。
- **C（拒）**：白名单无 guard——无分隔 juxtaposition `…结果当真` 经纯 CJK 白名单仍入 span 剥离 → PASS——正是 DEC-336 明拒的「disclaimer 后放行」等价缺陷。
- **CH-R5-1** 无分隔连写背书：Guard G 以既有三框架算子闭集硬拒，全部已知肯定背书形闭合；未知新背书形不在闭集 → 残文照扫（保守）。
- **CH-R5-2** 合法载荷含 guard token 被保守拒：真实窗口零例（C6 载荷无 token）；成本=该行 BLOCK 走新票扩闭集，不默过不投机归类。
- **CH-R5-3** escape/offset 构造：切片-解析值逐字符一致校验 + raw 映射 + 计数 ToolFault + 整拒规则——任何不一致故障传播为 BLOCK（含 safe 输入）。
- **CH-R5-4** 白名单边界（CJK 扩展/未知 Unicode/全角空格）：范围外一律终止（保守；扩展新票+溯源）。
