## 3. 门禁口径（M-2 实测基准）

### 3.1 Check 31 重定标——候选方案对照（评估标准预定义；R0-F1 处置）

**预定义评估标准**（五条，决策前确立）：①可复算性（预算值与依据可独立复算）②增长裕度（是否公式化覆盖治理数据自然增长）③回退成本（撤销重定标的代价）④判定语义影响（BLOCKED→PASS 的语义是否仍有据）⑤维护成本（超限再现时的人工介入量）。

| 评估标准 | **A 容量重定标 + provenance（选定）** | B 削减治理记录 | C 纯归档消解 |
|---|---|---|---|
| ①可复算性 | 高——baseline 登记 + 裕度公式（实测×1.2） | 低——削减量随增长漂移无锚 | 中——归档后复测可复算 |
| ②增长裕度 | 公式化覆盖 | 无——持续再削减 | 无——增长持续必再撞限 |
| ③回退成本 | 低——还原预算值 + 基线注销即回 | 高——被削记录需回补且失真 | 不适用 |
| ④判定语义 | BLOCKED→有据 PASS（门禁语义不弱化） | PASS 面不变但记录完整性受损 | 暂时 PASS（不可持续） |
| ⑤维护成本 | 一次性 + M-2 定期复算 | 每次超限人工裁决削减面 | 每次归档人工再评估 |

**排除理由**：B 违反机录时代完整性公理（DEC-220：受管状态变更零人工直写+全部可对账——削减热面记录=丢弃对账凭证，且 evidence-log 8,920 units 全部为合法机录行）；C 治标——0.87 开发期继续机录（本规划自身的 TRIAGE/EVD/DEC 行即增量），归档只削历史不挡增长斜率，且 M-8 归档已入范围作为辅助卫生（非解药）。**选定 A**：预算上限从 300,000 重定至带基线登记的新值，经 baseline-register 登记口径（FEAT-047 机制承载）；重定标数值与依据在 FIX-369 票内同 change 落地。红线：不得写成「豁免超限」。
