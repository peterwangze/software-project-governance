## §3（替换）背书框架否定前缀——全窗口闭合切分规范

**判定对象不变**：框架闭集（三框架）、全 input 作用域、record 残文同规——全部沿用 R1/R2。本节只定义「否定前缀豁免」的取得条件。

### 3.1 前缀窗口（完整、clause 有界、不截断）
- 窗口 = **当前小句起点至本框架运算子（把/将/当作/当成/视为/作为/当真 中最先出现者）起点**之间的全部字符。小句起点 = 距该运算子最近的 小句终结标点（`。；;，：`）之后 或 行/字段首。
- **跨小句不借用**：前一/其它小句中的否定 token 不计入本窗口（例：`不许忽略复核，把该结果当作真实数据`——框架小句起点在`，`后，窗口为空 → 计数 0 → 不豁免 → BLOCK）。
- **窗口长度 >16 字符 → 一律不豁免**（不取首/末 16 截断——截断会丢叠否定，禁止）；溢出即拒，方向保守。
- 本 clause 有界仅作用于**前缀分析**；框架本身的检测/拦截作用域仍为全 input（不因本节恢复任何断句截断）。

### 3.2 双封闭表（具体定稿，实现即此，无「实现期再定」）
- **否定 token 表**（longest-match 优先序）：`并非｜不允许｜禁止｜拒绝｜杜绝｜避免｜防止｜绝不｜决不｜从不｜从未｜毫无｜没有｜不会｜不能｜不得｜不可｜不｜未｜别｜勿｜莫｜无｜非`
- **填充 token 表**（封闭虚词集）：`应该｜应当｜是｜应｜再｜该｜此｜其｜的｜了｜也｜都｜就｜还｜且｜而｜与｜或｜会`
- **显式排除**（两表皆不含，作为残留即拒的锚例）：`常`、`来`、`论`——故 `非常`/`未来`/`无论` 不可能被切分为「否定+填充」（`非`+残留`常`、`未`+残留`来`、`无`+残留`论` → 残留 → 拒）。

### 3.3 切分与计数（确定性算法）
1. 从窗口**起点逐字符消费**：每位先试否定表 longest-match，再试填充表 longest-match，两者皆不中 → **残留**；
2. **全窗口必须被完整消费**（无跳字、无子串跳过、无残留）——出现任何残留字符 → 不豁免；
3. 计数 = 消费到的否定 token 总数：**==1 且全窗口合法 → 单层否定，豁免该框架**；**==0、≥2、有残留、或窗口溢出 → 不豁免，框架照 BLOCK**；
4. 无语义判定、无新 regex 白名单——纯闭表 longest-match + 整数计数 + 残留布尔（与术语核「约束中隔/叠否定」同一闭表哲学）。

### 3.4 推演验证（逐例过表）
| 前缀窗口 | 切分 | 计数/结果 |
|---|---|---|
| `非常应当` | `非`(否定)+`常`残留 | 残留 → 拒 → BLOCK |
| `未来将`（框架`将把…视为`，窗口至首个运算子`将`前=`未来`） | `未`+`来`残留 | 残留 → 拒 → BLOCK |
| `无论复核与否` | `无`+`论`残留 | 残留 → 拒 → BLOCK |
| `不是不`（`…不是不把…`） | `不`+`是`(填充)+`不` | 2 → BLOCK |
| `并非不`（`…并非不将…`） | `并非`+`不` | 2 → BLOCK |
| `不允许不` | `不允许`+`不` | 2 → BLOCK |
| `不允许` | `不允许` | 1 → PASS |
| `不`（`不把估计批戳当成真实戳`） | `不` | 1 → PASS |
| `未`（`未将该结果当作真实数据`） | `未` | 1 → PASS |
| 空窗口（`…复核，把该结果…`） | — | 0 → BLOCK |
