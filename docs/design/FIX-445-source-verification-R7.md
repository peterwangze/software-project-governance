## §1 B1 修复——三个最小有界形式语法（prose/residual 层；record typed-span/Guard G/身份链零触碰）

**共同约束**：三规则只作用于 prose/residual 层；豁免仅到**匹配的 literal occurrence/span**，其余全文保持 M5 全 input 框架检查与术语扫描；无 EVD 编号/任务/整句白名单；无整字段/整行/整 JSON 删除；旧 EVD 零编辑；不削任何既有安全门（裸 `当真` :770 触发保持，仅按下列闭规则被豁免）。

**F1（1536 形）或-析取名词短语否定**：`(NEG)(NP)(TERM)` 其中 NP = `ITEM(或|及|与|、)ITEM`（至多两个 joiner/三个 ITEM）；NEG ∈ 现行否定闭表前缀集；ITEM = 1..8 字符、字符 ∈ ｛CJK U+4E00..U+9FFF ∪ ASCII 字母数字｝，且 **ITEM 内不得含否定表任何 token**（最长匹配检）**与术语字 编/造/幻/觉 任一**（字节检）；NP 总长 ≤16；TERM=`编造|幻觉`；匹配即剥该 occurrence（sed :831 旧或形为其特例，可保留兼容或由本形取代，语义等价）。泛化：`不时间或权限编造`/`未复核或抽检幻觉`/`无预算或PASS编造` 同族自动覆盖，无需逐词白名单。

**F2（1587 形）后置强否定豁免**：frame match 的 operator 终点起至本小句终结（isterm 集=hook :726-728 现集）或 16 字符（先到者）的 **post-window** 内，按否定闭表位置扫描（最长匹配，非消费式）计数：**强否定集**｛不能|不得|不可|无法|禁止|拒绝|并非|未|别|勿|莫｝（裸 `不` **不在**）——强计数==1 且窗口内**否定 token 总数（强+弱）==1** → 该 frame 豁免（合规否认句）；总数 ≥2 → 叠否定维持 BLOCK；强计数==0 → 本规则不触发（回落前缀规则）。窗口内出现任何框架算子 → 不豁免（嵌套 frame 各自评估）。1587：`当真`后`不能…` 强 1/总 1 → PASS。

**F3（1588 形）锚定算子枚举提及**：极大连续段可被**完全** longest-match 切分为 **≥3** 个算子表 token（把/将/当作/当成/视为/作为/当真），且段起点前一字符 ∈ 封闭锚集｛含,括,列,即,是｝（或行/字段首）→ 段分类为技术枚举；**整段落于其内的 frame match 折扣**（不计 endorsement）；**越出段**（宾语 token 在段外）的 frame 照常触发。1588：`含`锚+7-token 段 → 段内 `当真` 等折扣 → PASS。无分隔连写与分隔形（、/，/space 连接的算子串）同规——joiner 属段外字符时切段（各段独立满足 ≥3 才折扣）。
