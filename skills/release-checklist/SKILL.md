# 核对本次发布操作

Release 将本次实际候选与版本、变更范围、制品标识和适用 CI 绑定。核对与这次变更有关的未结风险、部署步骤、健康信号、停止或回滚条件以及操作权限。对高风险数据变更先在可恢复环境验证回退或前滚方案。

Release Reviewer 独立复核同一候选和签核记录。用 `check-release --help` 查看宿主支持的候选检查，用户的发布或回滚授权须覆盖目标环境和影响。发布后记录实际制品与观测；偏离预期时停止扩大发布并沿授权恢复。

发布通过 Git 主线交接时，公开制品复验后，在下次会话使用的本地仓库运行 `python "<本技能目录>/scripts/check_mainline.py" <主分支> --remote <发布远端>`。将输出的本地和远端完整提交号记入本次发布回执。命令直接查询远端；退出码为 0 才能完成交接。

若本地主线落后，从发布远端 fetch，并仅以快进方式同步本地主线，再复跑检查。主线已在工作树中检出时，在对应工作树核实改动后执行快进；遇到分叉、改动冲突或远端不可访问时保留现场，记录阻塞。
