# 选择本轮活动与交接对象

协调者已确认目标、验收操作、单元 ID 和所处循环后，用[技能分工表](../software-project-governance/references/skill-index.md)选择能解决当前缺口的专业工作。派发写明实际输入、负责人、预期工件、复验者和父单元；接收者据原件决定下一步。

- 找不到合适方案时，在准备单元试用社区候选，把取舍与实测原件交给设计者。
- 设计、实现和内层复验可按依赖并行。发现阻塞时，将失败样本和所属单元交还给能修正它的角色。
- 已授权的 DSH 直修保留原生执行路径；真实成品交独立验收者。外层从真实使用中提取下一轮目标。

运行者从 `loop status --unit <id> --json` 读取本轮局部条件。
