# v0.101.0 发布范围

本次发布由用户在 DEC-400 授权。累计起点为 `v0.100.0` 剥离后的提交 `37ac96d322e4c874f0ba83ff6fe80b392fe2cb51`。开发起点 `d2148fd` 已包含 FIX-511、FIX-512 和 FIX-513。公开标签生成后，可运行 `git log --oneline v0.100.0..v0.101.0` 核实完整差异。

| 工作 | 发布前的验收条件 |
| --- | --- |
| FEAT-132 保留用户原意 | 在子任务用局部条件取得进展后，CLI、启动摘要和控制台仍能指回根目标及当前证据缺口。有授权的目标修订可追溯，旧单元可恢复。用同一原始判据对照实际候选和回执，交给独立验收者决定整件交付、原条件返工或需要的下一步。 |
| AUDIT-167 游戏 | 从同一故障修订 `69f092a` 开始，对照 v0.100.0 与候选工作流。独立从标题开档，进入并退出图鉴，移动、交互、保存并读档。记录 Tuxemon v0.5 提供的参照与实际判据。 |
| AUDIT-167 命令行工具 | 从 Click 修订 `cd9bdd9` 开始，用同一分页输入验证分页结束后调用方仍能写入标准输出。用上游修订 `4df304c` 校准判据，保留可重放的输入、输出和退出状态。[上游修复](https://github.com/pallets/click/pull/3533) |
| FIX-511 至 FIX-513 | 重放共享快照并发冲突及晚读结果，核对 Ubuntu 与原生 Windows CI，以及热账与归档中的历史证据计数。 |
| REL-105 正式发布 | 独立签核绑定实测源码树。经核准的转换提交有附注标签，从其构建的包可离线安装；GitHub 正式附件经下载复核，公开标签所属提交可从主干到达。[发布核对清单](release-checklist-0.101.0.md) |

配对实测在每个领域固定输入、预算和验收条件，独立验收者在揭示版本前保存判定。候选的两条完整旅程须通过，已知失败件、偏离原意的局部成功须被识别，合格对照须放行。记录包括失败、未完成、开销和可复验的新机会。这两个样本限定本次质量结论的适用范围。[评测协议及实测记录](../research/delivery-comparison-0.101.0.md)

双领域实测封存后，组装审查补登记了仓库中的两支复跑脚本，并将随 npm 包交付的控制台文件归入产品清单。两次生产者使用的快照指纹见实测记录。正式包另含此次清单归类及发布账本，按对应 Git 树重新构建、安装和验收。

首个候选的本机发布门还发现历史版本聚合测试会加载当前宿主的真实成品契约。后继组装隔离了这项测试依赖，重新核验实际安装包、签核和完整发布门。生产者使用的治理代码、游戏及 Click 评测输入均可与上述冻结试验追溯比对。
