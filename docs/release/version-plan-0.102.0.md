# 0.102.0 发布范围

REL-107 从上一版标签 `v0.101.1`（`1ed1ce7a0a79`）累计组装。FEAT-133 与 FIX-549 的产品基线为 `7a86b4a4`。本版让 LLM 在材料增长后仍能从固定治理入口定位回答当前问题所需的原件。

| 范围 | 可复验的结果 |
| --- | --- |
| 启动与派发 | 用 `governance-bootstrap --format json` 取得当前单元、判据和材料查询命令。加入无关材料后，普通启动包仍省略历史学习正文。按任务派发时只带入相应单元。 |
| 定位与查阅 | `loop materials --unit <id> --query <问题词>` 从该单元记录和共享任务证据中返回最多三条摘要。按返回的 `--ref` 查位置，在所选原件中读取必要片段。历史或已替代记录带有状态。 |
| 归档与收口 | 复用 plan、evidence、decision、risk 及原生单元记录。新证据模板按写入器的十列登记。显式 `--check` 检查已登记本地引用和本单元、共享任务的托管目录，报告缺失、变更、未登记及无法核验的项目。 |
| 历史任务归属 | 受理时核对归档任务和证据中的编号，覆盖未被索引的标准卷。测试覆盖拒绝复用历史编号，以及恢复同一开放任务。 |

用 `git log --no-merges v0.101.1..7a86b4a4` 核对累计变更。候选、公开附件及回退的验证步骤见[发布核对清单](release-checklist-0.102.0.md)。
