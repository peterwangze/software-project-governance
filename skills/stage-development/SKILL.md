# 实现并验证本次修改

Developer 复现原始问题，追踪产生异常的调用路径，做覆盖根因的最小修改，重放失败输入和受影响的相邻行为。治理工具的代码、协议或投影由 Governance Developer 修改，并通过工具的实际入口复验。

内层 G6 可直接运行单元中已声明的命令验收。回执记录本单元本轮所用命令、预期、退出码与实际输出；失败继续修本单元。需要独立代码审查或受保护提交时，把候选工件和证据交 Code Reviewer。只有需要长期防住的具体回归才补专项测试，覆盖率沿用项目的适用约定。
