## 仍待实证的范围

- DSH 防护原型的宿主工具管线已有隔离实测。未携带修订锚的派发、真实模型答复和完整消费方工作流仍各有验证条件。0.2.2-rc.5 的 headless 入口探测停在 API 凭据边界。
- D1 已有真实消费项目的升级和任务样本。持续成功率、耗时、跨项目普适性及与标杆产品的比较仍待独立样本。下一轮可保留原任务、合格对照和失败样本，以相同输入、预算、验收条件比较结果。[工作流演进和重放方法](../governance/evolution.md)
- FIX-470–474 和 FEAT-105–110 维持冻结，FIX-476 保留为候选。真实使用出现对应需求或用户解冻后再评估。FIX-483 的风险状态计量仍待处理。
