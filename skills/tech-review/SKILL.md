# 复验技术候选与约束

## 循环角色

按准备 G3 或交付设计 G5 的实际问题复核候选试用、技术约束和取舍。 独立 Reviewer 按[共享签核规则](../software-project-governance/references/loop-role-mapping.md)记录本轮回执与未解决阻断数。

独立审查者先确认候选版本及其承诺解决的限制，再在同类宿主和真实输入上试用关键 API 或行为。核对依赖、兼容性、维护和许可中实际影响采用的问题。

说明观察到的边界、失败样本和保留风险。缺少关键试验证据时退回补验，已排除的候选可引用其原始记录。
